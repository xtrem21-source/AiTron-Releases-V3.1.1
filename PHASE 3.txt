SECTION 5 \f1\emdash  CALCUL AUTOMATIQUE DES PARAM\f0\'c8TRES OPTIMAUX\par
5.1 H\'e9ritage de la logique AiTron\par
Reprendre la logique de calcul d'AiTron (\'e9prouv\'e9e) :\par
\par
Calcul du nombre de couches GPU (-ngl) :\par
\par
python\par
def estimate_ngl(model_info, hw, ctx, margin_mb):\par
    """\par
    Calcule le nombre optimal de couches \'e0 d\'e9charger sur le GPU.\par
    Bas\'e9 sur :\par
      - VRAM libre (hw.vram_free_mb)\par
      - Marge de s\'e9curit\'e9 (margin_mb)\par
      - Taille du mod\'e8le (model_info.tensor_bytes)\par
      - Taille du cache KV (kv_cache_bytes(model_info, ctx))\par
    """\par
    if not hw.has_gpu or hw.vram_free_mb <= 0:\par
        return 0\par
    budget = (hw.vram_free_mb - margin_mb) * 1024 ** 2\par
    if budget <= 0:\par
        return 0\par
    kv_total = kv_cache_bytes(model_info, ctx)\par
    kv_per_layer = kv_total // model_info.n_layers\par
    per_layer = int((model_info.layer_bytes + kv_per_layer) * 1.10)  # marge 10%\par
    if per_layer <= 0:\par
        return 0\par
    compute_buf = (max(model_info.n_vocab, 32000) * 8) + (ctx * max(model_info.n_embd, 1) * 4)\par
    fit = (budget - compute_buf) // per_layer\par
    if fit >= model_info.n_layers and (budget - compute_buf - model_info.n_layers * per_layer) >= model_info.non_layer_bytes:\par
        return model_info.n_layers + 1  # tout sur GPU\par
    return int(max(0, min(fit, model_info.n_layers)))\par
