SECTION 3 \emdash  PYTHON EMBARQU\f0\'c9 (UNIQUEMENT POUR LITELLM)\par
3.1 D\'e9cision architecturale\par
Pourquoi Python embarqu\'e9 ?\par
\par
Coh\'e9rence avec la doctrine "Click and Go" : l'utilisateur ne doit rien installer\par
\par
Reproductibilit\'e9 : version Python fig\'e9e\par
\par
Isolation : Python ne sert que \'e0 LiteLLM, il ne touche pas au c\f5\u339?ur Go\par
\par
Pourquoi pas tout en Python ?\par
\par
Le c\u339?ur LocalAI (local-ai.exe) et le bridge (cloud-proxy.exe) sont compil\f0\'e9s en Go \f1\emdash  performants, autonomes, sans d\f0\'e9pendance\par
\par
Les passer en Python d\'e9graderait les performances et introduirait de la fragilit\'e9\par
\par
Les backends multi-modaux sont des binaires natifs (whisper.cpp, SD, kokoro)\par
\par
3.2 Version Python fig\'e9e\par
Version cible : Python 3.11.9 (embed amd64)\par
\par
Source : {{\field{\*\fldinst{HYPERLINK https://www.python.org/ftp/python/3.11.9/python-3.11.9-embed-amd64.zip }}{\fldrslt{https://www.python.org/ftp/python/3.11.9/python-3.11.9-embed-amd64.zip\ul0\cf0}}}}\f0\fs22\par
\par

\par
